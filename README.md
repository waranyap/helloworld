# How to Run

## 1. Install Python

Download Python from:

- https://www.python.org/

Verify installation:

```bash
python --version
```

---

## 2. Save the Program

Create a file named:

```text
junk_ship.py
```

Paste the Python code inside.

---

## 3. Run the Program

```bash
python junk_ship.py
```
